# DEVFLIX — React Tutorial 02

Projeto React + Vite inspirado na referência do tutorial: catálogo de cursos no estilo Netflix, com três fileiras horizontais, cartões de cursos, progresso dos cursos pendentes e modal demonstrativo.

## 1. Executar o projeto

Instale as dependências:

```bash
npm install
```

Inicie o servidor:

```bash
npm run dev
```

Abra o endereço mostrado pelo Vite (normalmente):

http://localhost:5173

## 2. Estrutura do projeto

- `src/components/Header.jsx` — cabeçalho
- `src/components/CourseCard.jsx` — cartão do curso
- `src/components/CourseSection.jsx` — fileira horizontal
- `src/components/VideoPlayer.jsx` — modal demonstrativo
- `src/data/courses.js` — dados e imagens dos cursos
- `src/App.jsx` — página principal

## 3. Tecnologias

- React
- Vite
- JavaScript
- CSS

## 4. Objetivo

Desenvolver uma interface de catálogo de cursos de programação inspirada na Netflix, praticando componentes React, organização de arquivos, apresentação de dados e interação com a interface.
