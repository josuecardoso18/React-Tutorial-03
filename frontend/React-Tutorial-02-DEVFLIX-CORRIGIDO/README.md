# DEVFLIX — React Tutorial 02

Projeto React + Vite inspirado na referência do tutorial: catálogo estilo Netflix com três fileiras horizontais, cartões de cursos, progresso dos cursos pendentes e modal demonstrativo.

## Executar

```bash
npm install
npm run dev
```

Abra o endereço mostrado pelo Vite (normalmente http://localhost:5173).

## Estrutura

- `src/components/Header.jsx` — cabeçalho
- `src/components/CourseCard.jsx` — cartão do curso
- `src/components/CourseSection.jsx` — fileira horizontal
- `src/components/VideoPlayer.jsx` — modal demonstrativo
- `src/data/courses.js` — dados e imagens dos cursos
- `src/App.jsx` — página principal
